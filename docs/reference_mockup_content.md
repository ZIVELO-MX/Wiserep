# Mockup mobile — contenido UI de referencia

Pantalla de sesión de entrenamiento activa. Se usó en el Hero del branch `feat/landing-page`.

## Estructura de la pantalla

### Header de sesión
- Label: `Entrenamiento` (uppercase, muted)
- Título: `Push · Día A`
- Badge progreso: `4 / 5` ejercicios

### Ejercicio actual
- Label: `Ejercicio actual` (uppercase, muted)
- Nombre: **Hip Thrust**
- Subtítulo: `Empuje de cadera · Glúteos`
- Badge serie: `Serie 3/4`

### Tracking de carga
- Peso actual: **60 kg**
- Repeticiones: **12 reps**
- Peso anterior (referencia): **55** (opacidad reducida, label "anterior")

### CTA de serie
- Botón primario: `Completar serie`

### Timer de descanso
- Label: `Descanso` (uppercase)
- Tiempo: **1:30** (prominente, azul)
- Botón play circular

### Feedback de sensación
- Label: `¿Cómo se sintió?`
- Opciones: `Muy fácil` / `Bien` / `Pesado` / `Mucho`
- Estado seleccionado: `Bien` (azul)

## Notas de diseño

- Fondo del teléfono: `#0F172A` (slate-900)
- Pantalla interior: `#F8FAFC` (slate-50)
- Color primario: `#2563EB` (blue-600 / WiseRep Blue)
- Dynamic Island en la parte superior
- Home indicator en la parte inferior
- Sin status bar (hora/wifi/batería)
