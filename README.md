# WiseRep

> Entrena mejor, repetición por repetición.

WiseRep es el primer módulo de entrenamiento del ecosistema **Gymoss** — una plataforma modular de software para gimnasios.

## ¿Qué es WiseRep?

Una PWA en español para atletas y entrenadores que permite:

- Seguir rutinas de entrenamiento
- Registrar pesos, series y repeticiones
- Usar timers entre series
- Sustituir ejercicios
- Reportar cómo se sintió el entrenamiento
- Obtener sugerencias de progresión inteligente

## Tech Stack

- **Frontend:** Next.js + TypeScript + Tailwind CSS
- **Database:** PostgreSQL via Supabase + Prisma ORM
- **Auth:** Supabase Auth
- **Deploy:** Vercel
- **Arquitectura:** PWA-first, Mobile-first, Spanish-first
